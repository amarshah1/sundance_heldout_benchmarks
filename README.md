# Held-out Verus SMT benchmarks

SMT queries generated by [Verus](https://github.com/verus-lang/verus) from four
Verus projects that are not in the SMT-LIB
[`UFDTLIA/20241211-verus`](https://smt-lib.org/benchmarks.shtml) benchmark set.
Each project was verified with the Verus version it pins, with SMT logging on
(`--log smt`), and every `(check-sat)` in the logs became one file.

## Layout

```
UFDTLIA/<project>/     quantifiers, uninterpreted functions, datatypes, linear integer arithmetic
nonlinear/<project>/   queries that need nonlinear integer arithmetic
bitvector/<project>/   queries from Verus's by(bit_vector) mode
```

`nonlinear/` holds 71 queries from Verus's `by(nonlinear_arith)` mode and 80
default-mode queries that need nonlinear reasoning.

## Changes from Verus's output

- z3's built-in `(_ partial-order 0)` is replaced by an uninterpreted
  function with axioms, as in the SMT-LIB `20241211-verus` set.
- z3's `update-field` is replaced by constructor applications (38 CortenMM
  queries), as upstream Verus has emitted since
  [verus-lang/verus#2409](https://github.com/verus-lang/verus/pull/2409).
- Verus's z3 options are listed in each file's `:source` header, not set.
